# OOMKilled и давление памяти

## Признаки
Контейнер завершён с reason OOMKilled или exit code 137; возможны рестарты.
Node pressure и eviction — отдельный симптом, их не смешивай с лимитом контейнера.

## Частые причины
Утечка, слишком маленький memory limit, крупный batch, кэш или конкуренция за память ноды.
Недостаток request влияет на планирование, но сам по себе не доказывает OOM.

## Как проверить
Используй describe pod для Last State и events для MemoryPressure/eviction.
Сними top по namespace, отметь degraded при отсутствии metrics-server.
Сверь resources каждого контейнера с usage и предыдущей ревизией workload.
Посмотри previous-лог перед убийством, не сохраняя чувствительные строки.

## Как исправить
Сначала отдели утечку от неверной границы и зафиксируй evidence.
Предложи изменение resources или env только в Deployment/StatefulSet через подтверждённый патч.
После подтверждения проверь rollout, usage и отсутствие новых OOMKilled.

## Чего не делать
Не поднимай лимит вслепую и не принимай degraded как нормальное потребление.
Не меняй image, node policy или security fields для обхода проблемы.
Не стирай старые рестарты и не утверждай успех без нового измерения.
