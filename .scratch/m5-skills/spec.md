# М5: знания агента — скиллы, SOUL, IDENTITY, runbooks (ТЗ §7, F9)

Статус: реализовано, PR. Срок защиты 2026-10-13: этап одним PR.

## Зачем

ТЗ §7 требует шесть скиллов в `skills/<name>/SKILL.md` (фронтматтер name, description, triggers, tools) и
семантические файлы в `agent/`: SOUL, IDENTITY, MEMORY, RUNBOOKS. Без них агент рассуждает только тем, что
знает модель. Скилл даёт процедуру опытного SRE: какие инструменты, в каком порядке и что считать
доказательством. SOUL задаёт принципы, которые модель не может переписать. Runbook отвечает на общие
вопросы (маршрут `runbook_qa`) без похода в кластер.

На М4 это было видно живьём: модель теряла `previous: true` у логов и не знала, где взять имя ключа Secret,
который ей читать нельзя. Скилл crashloop закрывает оба места явными шагами.

## Что сделано

- `knowledge.py`: SOUL (и IDENTITY оркестратору) в системный промпт каждого узла; скилл выбирается кодом
  по `triggers`, побеждает больше совпадений, при равенстве — более длинные; runbook — по оглавлению
  (PageIndex): модель выбирает раздел по заголовкам, в промпт идёт только он.
- Тексты: 6 скиллов, SOUL, IDENTITY, MEMORY, 5 runbooks (черновик — Codex, вычитка и правки по живым прогонам).
- `--show-skill`: печать подключённого скилла; в отчёте строка «Скилл: …».
- По живым прогонам:
  - из `k8s_get_manifest` вырезаны `managedFields` и `last-applied-configuration`: манифест api уменьшился
    с 7.7 до 2.8 тыс. символов, env доходит до модели целиком;
  - в скилле crashloop — явный шаг «прочитай манифест здорового соседа»;
  - причины поломок убраны из аннотаций объектов стенда: агент читал ответ прямо из манифеста.

## Почему не проще

| Вариант | Почему нет |
|---|---|
| Скилл выбирает модель | Лишний вызов, и выбор нельзя проверить тестом; по триггерам он детерминирован и виден в отчёте |
| RAG по чанкам runbooks | Runbook — процедура, разрезание ломает порядок шагов; оглавление целиком влезает в промпт (MEMORY §4) |
| Без скиллов, «модель и так знает» | Живой М4: модель не брала лог предыдущего запуска и не знала, откуда взять имя ключа Secret |
| Скилл ограничивает инструменты (`tools` как allow-list) | Граница безопасности — уже набор read-only инструментов (М2); `tools` в скилле — подсказка, а не второй рубеж |
