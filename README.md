# k8s-incident-agent

Мультиагентная система диагностики инцидентов в Kubernetes. Инженер описывает проблему словами,
агент сам собирает факты read-only инструментами, сопоставляет с памятью о прошлых инцидентах
и предлагает исправление. **Любое изменение в кластере — только после подтверждения человеком.**

Курсовой проект. Техническое задание — `docs/TZ.md`, план работ — `.scratch/roadmap.md`.

**Продолжаешь работу с новой сессии агента? Начни с `.scratch/HANDOFF.md`.**

## Требования

`uv`, Docker Desktop, `kind`, `kubectl`. Если `uv` ставился официальным инсталлятором, он лежит
в `~/.local/bin` — Makefile добавляет этот путь в `PATH` сам.

```bash
brew install kind          # если ещё не стоит
open -a Docker             # демон должен быть запущен
```

## Быстрый старт

```bash
make install               # зависимости
make check                 # линт + юнит-тесты, кластер не нужен
make stand                 # поднять kind и внести все поломки (S1-S4)
make demo-secrets          # сломанный под виден; Secret: отказ RBAC, затем ***masked***
make demo-s1               # агент: диагноз S1 → патч → ваше подтверждение → применение
make demo-s6               # агент: запрос вне области — отказ без вызова инструментов
make demo-s5               # агент: S1 ещё раз — находит прошлый случай в памяти и ссылается на него
make isolation-test        # права учёток, секреты, контейнер, сеть агента (М2)
make agent-tool TOOL=k8s_list_pods ARGS="--ns payments"   # то же из контейнера агента
```

## Карта репозитория

```
docs/          ТЗ, архитектура, память, изоляция, evals, наблюдаемость, выбор LLM
docs/DEFENSE.md  вопросы защиты и ответы на них, наполняется по ходу работы
src/           Python-пакет: конфиг, свидетельства, маскирование, инструменты, CLI
stand/         kind-кластер и «сломанные» манифесты для сценариев S1-S4
tests/         юнит-тесты (уровень 2 из docs/EVALS.md)
.scratch/      план работ и рабочие заметки
```

## Безопасность

`local.env` содержит боевой токен LLM-шлюза и закрыт `.gitignore`. Токен не печатается ни в одной
команде: `make config-show` выводит его как `***masked***`.
